# フローライト Eye モニター Info

**開発：株道経済研究所**  
Windows向け・モニター情報表示／目視診断ツール

モニターの情報を確認し、画面の表示状態をチェックするためのWindows向けツールです。

新しく購入したモニターの確認、中古モニターの購入前チェック、長く使っているモニターの定期点検などに活用できます。

## Windowsのセキュリティ警告について

初めて本ソフトを起動すると、WindowsのMicrosoft Defender SmartScreenにより「WindowsによってPCが保護されました」と表示される場合があります。

個人開発のアプリなど、Windowsが発行元やアプリの評判を十分に確認できない場合にも、この警告が表示されることがあります。

実行するか判断する際は、公式GitHubリリースから入手したファイルであることを確認してください。実行すると判断した場合、画面に「実行」ボタンが表示されていなければ「詳細情報」をクリックすると表示されます。ファイルの安全性に不安がある場合は、実行せずにキャンセルしてください。

また、本ソフトの配布用実行ファイルは、主要なセキュリティソフトを含む71種類のセキュリティエンジンを備えた**VirusTotal**でスキャン済みです。**66種類のセキュリティエンジンで良好な検査結果が得られました。** 一方、5種類のエンジンでは検出が報告されています。Python製アプリをEXE化した際には、機械的な判定によって誤検知が発生する場合があります。

起動する前に、次の点を確認してください。

- ダウンロード元が、このREADMEに記載された公式GitHubリリースであること
- ファイル名が `FluoriteEyeMonitorInfo.exe` であること
- 配布元やファイルに不審な点がないこと

不安がある場合は、無理に実行せず、起動を中止してください。警告を回避するためにWindowsのセキュリティ機能を無効にする必要はありません。

## 主な機能

### 1. モニター・PC情報の表示

EDIDやWMIなどから取得できる情報を表示します。

- モニターの機種・製造情報など（取得できる場合）
- モニターの接続情報
- 解像度、色深度、リフレッシュレートなどの表示情報
- PC・Windowsに関する情報

取得できる項目は、モニター本体、接続方式、ドライバー、Windowsの環境などによって異なります。機種名や製造情報が表示されない場合でも、それだけで故障を意味するものではありません。

### 2. モニターの目視診断

検査パターンやサンプル画像を利用して、画面の表示状態を目視で確認できます。

確認項目の例：

- ドット抜け・常時点灯
- 色むら・輝度むら
- 光漏れや暗部のむら
- 焼き付き・残像の疑い
- 色表示・階調などの表示状態
- 文字や輪郭の表示状態

本ソフトは、不具合を自動検出して故障の有無を断定するものではありません。利用者自身が目で確認するための診断支援ツールです。

## 開発者

**株道経済研究所**

CrystalDiskInfoのように、必要なときに起動して機器の状態を確認できる、長く使ってもらえる定番ツールをモニター向けにも作りたい。その発想から、本ソフトの開発を始めました。

本ソフトでは、取得できる情報は自動表示し、目視が必要な項目は検査パターンやサンプル画像を使って確認する方式を採用しています。

利用してくださる方のご意見を参考に、改善を続けていきます。

## 不具合報告・改善要望

不具合の報告や改善案は、GitHubリポジトリの[Issues（課題）](https://github.com/goburin-xx/fluorite-eye-monitor-info/issues)からお寄せください。

報告の際は、可能な範囲で次の情報を記載していただくと、原因の調査に役立ちます。

- Windowsのバージョン

- 表示されたエラーメッセージ

## ご利用上の注意

- 表示できる情報は、機器や接続環境によって異なります。
- 目視診断の結果は、モニターの正常性や故障の有無を保証するものではありません。
- 画面の見え方は、モニターの設定や周囲の明るさなどによっても変わります。
- 異常が疑われる場合は、別の接続ケーブルやPCでの確認、メーカーの案内なども参考にしてください。
